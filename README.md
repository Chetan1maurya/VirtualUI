# Virtual UI

This is Full stack project. Objective of this project is to create web UI components and integrate them easily. Also user will get some free credits to generate UI components using AI and if required they can buy more credits to generate more components.

## 📌 Features

- Generate UI components using AI
- Integrating UI components easily in other web application
- Google Authentication
- Save components for personal usecase
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- Git & GitHub
- Postman

## ⚙️ Installation & Setup in local machine

### Prerequisites

Make sure you have the following installed:

- Node.js (v18 or higher)
- npm
- Git
- MongoDB / MongoDB Atlas account

### 1. Clone the Repository

```bash
git clone http://github.com/Chetan1maurya/VirtualUI.git
cd VirtualUI
```
### 2. Install Dependencies
```bash
cd virtualui-client
npm install
```
```bash
cd ../virtualui-server
npm install
```
